# 学年 1 位製造 AI

最短で学年 1 位を取るための最適化学習プランを生成する AI アプリケーション。

## 機能

- 📊 **教科分析**: テスト範囲の重要ポイントと頻出内容を自動分析
- 🎯 **弱点特定**: ユーザーの理解度から弱点を推定
- 📅 **学習計画**: 今日やるべき最適な学習内容を自動生成
- 📝 **問題生成**: 弱点を狙った問題を自動作成
- 🔮 **点数予測**: 現在の実力と学年 1 位ラインを計算
- 🚀 **次のアクション**: 今すぐやるべき行動を提示

## 技術スタック

- React 18
- Vite
- CSS3 (Gradient, Animation)

## セットアップ

```bash
cd grade-ai
npm install
npm run dev
```

## 使用方法

1. 教科名を選択（数学・英語・国語・理科・社会）
2. テスト範囲を入力
3. 現在の理解度（%）を入力
4. 過去の点数（任意）を入力
5. 「学習プランを生成」ボタンをクリック

AI が以下の情報を JSON 形式で生成：
- 分析結果
- 弱点分析
- 今日やるべきこと
- 自動生成問題
- 点数予測
- 次のアクション

## 内蔵 AI 設計

### システムプロンプト
`src/prompts.js` に定義されたシステムプロンプトにより、AI は以下の役割を果たす：
- 学年 1 位製造 AI としての振る舞い
- JSON 形式での出力強制
- 弱点優先の出題戦略
- 全教科対応

### データ構造
```json
{
  "subject": "教科名",
  "range": "テスト範囲",
  "analysis": "分析内容",
  "weakness": "弱点推定",
  "study_plan": "学習計画",
  "problems": ["問題 1", "問題 2"],
  "prediction": "点数予測",
  "next_action": "次のアクション"
}
```
